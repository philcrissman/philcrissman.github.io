Quicksort

Implemented in place in JavaScript, visualized with Raphael.js — Philip Crissman

Quicksort implemented in place in JavaScript, with the sorting process rendered step-by-step as an SVG diagram using RaphaelJS. Each element is assigned a color that follows it through every swap and partition.

All three modes create an array of 20 elements. Random uses random numbers between 0 and 99; Sorted and Reverse Sorted demonstrate worst-case behavior for this pivot-selection strategy.

Click one of the array links above to start the animation. The column on the left labeled PIVOT shows each partition's pivot element as it is selected; the arrows trace where each element moves at each step. The visualization grows downward as recursion proceeds.
