Mergesort

Bottom-up mergesort in JavaScript, visualized with Raphael.js — Philip Crissman

Mergesort works by repeatedly merging sorted subarrays into larger sorted subarrays. This visualization uses the bottom-up iterative form: start with 16 individual elements (subarrays of size 1, trivially sorted), then merge adjacent pairs, then merge those results, and so on until the whole array is sorted.

Each row shows one complete pass. Each element keeps its color throughout, so you can follow any individual value as it finds its sorted position. Elements moving left during a merge cross over elements moving right — those crossings are where the interesting comparison work is happening.
